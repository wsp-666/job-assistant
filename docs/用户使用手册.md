## 1. 产品简介

**求职助手**是一款面向个人求职者的本地工具，帮助你采集 BOSS 与企业官网岗位、生成个性化沟通话术、管理完整投递进度，并按优先级辅助填写网申表单。

### 你能用它做什么

| 功能 | 说明 |
|------|------|
| 自动读取岗位 JD | 在 BOSS 岗位页一键抓取职位信息 |
| 智能匹配打分 | 根据简历和筛选条件给岗位打分（0–100） |
| AI 生成打招呼语 | 结合简历和 JD 自动生成 80–150 字话术 |
| 一键填入输入框 | 将话术填入 BOSS 沟通框（需你手动发送） |
| 多维投递管理 | 表格、看板、日历、P0–P4、跟进提醒与进度时间线 |
| 优先级投递队列 | 按优先级和匹配分打开岗位，等待登录并自动填写官网表单 |

### 设计原则

- **确认优先**：默认自动填写、最终提交由你确认；只有显式开启高风险模式才尝试自动提交。
- **本地优先**：简历、岗位、话术数据保存在你的电脑上，不上传云端。
- **可编辑**：所有 AI 生成的话术都可以在发送前修改。

## 2. 系统组成

本工具由三部分协同工作：

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  Edge 浏览器插件  │ ←→ │   本地 API 服务   │ ←→ │   Web 管理台     │
│  (读页面/填话术)  │     │  (AI/数据库)     │     │  (配置/管理)    │
└─────────────────┘     └─────────────────┘     └─────────────────┘
         ↓                        ↓
    BOSS 直聘网页            本地 SQLite 数据库（data/job_assistant.db）
```

| 组件 | 访问地址 | 作用 |
|------|----------|------|
| 本地 API | http://127.0.0.1:8000 | 简历解析、岗位存储、AI 生成、匹配打分 |
| Web 管理台 | http://127.0.0.1:8000 | 上传简历、配置筛选、查看岗位和话术（与 API 同端口） |
| Edge 插件 | 浏览器工具栏 | 在 BOSS 页面抓取 JD、生成并填入话术 |

> **重要**：安装版用户需 **启动器运行中（API 8000）+ 插件**；管理台与 API 同一地址，无需单独开 5173 开发服务器。

## 3. 环境要求

### 硬件与系统

- 操作系统：Windows 10 / 11
- 内存：建议 4GB 及以上
- 磁盘：至少 500MB 可用空间

### 软件依赖

| 软件 | 用途 | 如何检查 |
|------|------|----------|
| Python 3.11+ | 运行后端 API | 命令行输入 `python --version` |
| Node.js 18+ | 运行 Web 和插件构建 | 命令行输入 `node --version` |
| MySQL 5.7+ / 8.0 | 仅云端账户/会员服务需要；普通本机用户不需要 | 可选 |
| Microsoft Edge 114+ | 加载插件、使用侧边栏 | Edge 设置 → 关于 Microsoft Edge |
| 网络连接 | 调用 AI API（可选） | 生成话术时需要 |

### AI 服务（可选但推荐）

- 默认支持 **DeepSeek**（兼容 OpenAI 接口格式）
- 也可使用通义千问、OpenAI 等兼容服务
- 未配置 API Key 时，系统会使用**本地模板话术**（质量较低，但可用）

## 4. 安装与启动

### 4.1 普通用户：安装包安装（推荐）

**发给用户的文件：** `dist\JobAssistant-Setup.zip`（约 50MB）

用户操作：

1. 解压 ZIP 到任意文件夹
2. 双击 **`Setup.bat`** 或 **`安装求职助手.bat`**
3. 等待复制完成（约 1–3 分钟），桌面会出现「求职助手」快捷方式
4. 双击桌面图标 → **一键启动** → **打开管理台**
5. 在 **设置 → 会员激活** 输入 Key
6. Edge 加载插件：选择安装目录下的 **`extension`** 文件夹（如 `%LOCALAPPDATA%\JobAssistant\extension`）

> 安装后无需 Python、MySQL、Node.js，全部已内置。

**开发者重新打包安装包：**

```powershell
cd "C:\path\to\求职助手"
.\scripts\build-installer.ps1
```

输出：`dist\JobAssistant-Installer\` 和 `dist\JobAssistant-Setup.zip`

---

### 4.2 开发者：源码安装

1. 打开 **PowerShell**
2. 进入项目目录：

```powershell
cd "C:\path\to\求职助手"
```

3. 运行安装脚本：

```powershell
.\scripts\install.ps1
```

安装脚本会自动完成：

- 创建 Python 虚拟环境并安装后端依赖
- 安装 Web 管理台和插件的前端依赖
- 生成插件图标
- 若不存在 `.env`，会从 `.env.example` 复制一份

安装过程约 1–3 分钟，请耐心等待。

### 4.3 数据库与会员（首次）

**数据库（默认 SQLite，无需安装 MySQL）**

首次启动 API 会自动在项目下创建 `data/job_assistant.db`，无需额外配置。

若你更熟悉 MySQL，可在 `.env` 中设置 `DB_BACKEND=mysql` 并填写 `MYSQL_*` 项。

**会员 Key**

1. 在 `.env` 中设置 `LICENSE_ADMIN_SECRET`（随机长字符串，仅你自己知道）
2. 生成 Key 发给用户或朋友：

```powershell
cd "C:\path\to\求职助手"
.\.venv\Scripts\python.exe scripts\generate-license.py --plan friend --count 3 --note "给朋友"
```

| 套餐 plan | 说明 |
|-----------|------|
| `friend` | 亲友免费，永久有效 |
| `monthly` | 月度会员（30 天） |
| `yearly` | 年度会员 |
| `lifetime` | 终身会员 |

3. 用户在管理台 **设置 → 会员激活** 输入 Key 即可

> 未激活时仍可打开管理台，但 AI 打分、生成话术等需会员功能不可用。

**API Key 配置**（推荐在 Web 设置页完成，无需改 `.env`）：

启动服务后打开 **设置** 页，在「API 配置」区域分别管理：

| 类型 | 用途 | 支持的服务 |
|------|------|------------|
| 识图 API | 扫描版简历 PDF 文字识别 | 百度 OCR |
| 分析 API | AI 生成打招呼话术 | DeepSeek、OpenAI 兼容、自定义 |

可添加多个 API 配置，通过单选框选择当前使用的接口。Key 保存在本地数据库，不会回显明文。

> 若你曾在 `.env` 中配置过 Key，首次打开设置页时会自动导入为可选项，之后建议在设置页管理。

**可选：`.env` 备用配置**（不填也可，在设置页配置即可）：

```env
LLM_API_KEY=你的API密钥
BAIDU_OCR_API_KEY=你的百度API Key
BAIDU_OCR_SECRET_KEY=你的百度Secret Key
```

### 4.4 每次使用前启动

**推荐方式：双击 `启动求职助手.lnk` 或 `启动求职助手.vbs`**（无黑窗、无弹窗）

也可双击 `启动求职助手.bat`（可能闪一下命令行窗口）。

首次使用需先打包启动器（只需一次）：

```powershell
cd "C:\path\to\求职助手"
.\scripts\build-launcher.ps1
```

完成后会出现：

| 入口 | 位置 |
|------|------|
| **启动求职助手.lnk** | 项目根目录（最推荐） |
| **启动求职助手.vbs** | 项目根目录 |
| **启动求职助手.bat** | 项目根目录（备用） |
| **JobAssistant.exe** | `JobAssistant\` 文件夹内 |

> 根目录没有单独的 `.exe` 文件是正常的；请用上面的快捷方式或 bat 启动。

启动器是一个**桌面小窗口**（不是一连串弹窗）：

| 按钮 | 作用 |
|------|------|
| **一键启动** | 后台启动服务（不再自动弹管理台窗口） |
| **打开管理台** | 打开本地管理台（含快速上手指南） |

关闭启动器窗口（点 **X**）会立刻关闭界面，并**自动在后台停止服务**（释放 8000 端口，无弹窗）。

启动成功后访问：

- 管理台：http://127.0.0.1:8000
- API 健康检查：http://127.0.0.1:8000/health（应显示 `{"status":"ok"}`）

### 4.5 关闭服务

直接**关闭启动器窗口**（点 X）即可结束后台进程。  
下次使用前重新双击 **`启动求职助手.bat`** 或 **`启动求职助手.vbs`** 即可。

> 旧方式 `.\scripts\start.ps1` 现已改为打开图形启动器，不再推荐手动开 PowerShell。

## 5. 首次配置

建议按以下顺序完成首次配置（约 5 分钟）：

### 步骤 1：上传简历

1. 打开 http://127.0.0.1:8000
2. 点击顶部导航 **「简历管理」**
3. 点击 **「上传简历」**，选择你的简历文件
4. 支持格式：`.pdf`、`.docx`
5. 上传后系统会自动解析技能、经历、项目等信息

> 第一份上传的简历会自动设为「默认简历」。

### 步骤 2：配置 API 与目标岗位

**2a. 配置 API（设置页）**

1. 点击顶部导航 **「设置」**（http://127.0.0.1:8000/settings）
2. 在 **识图 API** 区域：若简历可能是扫描版 PDF，添加百度 OCR 并填入 Key，选中为当前使用
3. 在 **分析 API** 区域：添加 DeepSeek 等接口并填入 Key，选中为当前使用

**2b. 配置目标岗位与筛选（目标岗位页）**

1. 点击顶部导航 **「目标岗位」**（http://127.0.0.1:8000/target-positions）
2. 填写以下信息：

| 配置项 | 说明 | 示例 |
|--------|------|------|
| 目标岗位 | 自上而下分层配置，每层一个岗位；卡片显示简介，点击可查看详情并编辑；支持上移/下移调整优先级 | 第 1 层：前端开发工程师；第 2 层：全栈工程师 |
| 岗位性质 | 可多选：全职 / 实习 / 兼职 / 校招；不选表示不限 | `实习` |
| 目标城市 | 可多选 | `北京`，`上海` |
| 薪资类型 | 月薪（K/月）与日薪（元/天）可同时启用，实习岗常用日薪 | 月薪 8K~15K + 日薪 200~350 元/天 |
| 最低/最高月薪 | 可选「不限」或填写范围 (K) | `15` ~ `30` |
| 最低/最高日薪 | 启用日薪后可设范围 (元/天) | `200` ~ `400` |
| 休息制度 | 不限 / 必须双休 | `必须双休` |
| 五险一金 | 勾选后 JD 未提及则待遇分降低 | 勾选 |
| 待遇期望 | 年终奖、提成、餐补、包住宿等，影响待遇匹配分 | 期望餐补、包住宿 |
| 必须包含关键词 | JD 中希望出现的词 | `React，TypeScript` |
| 排除关键词 | 含这些词则职责分降分 | `外包，驻场，996` |
| 话术风格 | 简洁 / 正式 / 热情 | `简洁` |
| 每日沟通上限 | 建议 20–30 | `30` |

3. 点击 **「保存」**

**目标岗位分层说明：**

- 列表从上到下表示求职优先级，越靠上越优先
- 每层卡片展示岗位名称和简介；点击卡片可编辑名称、简介、详细说明和匹配关键词
- 点击 **「+ 添加目标岗位」** 后才会出现填写表单
- 每层右侧可用 ↑ / ↓ 调整顺序，× 删除该岗位

### 步骤 3：安装 Edge 插件

见下一章。

### 步骤 4：验证连通性

1. 管理台 **「仪表盘」** 应显示 **API 已连接 ✅**
2. Edge 插件侧边栏应显示 **本地 API：已连接**

## 6. 安装 Edge 插件

### 6.1 加载插件（首次）

**方法一：快捷脚本**

```powershell
.\scripts\open-edge-extensions.ps1
```

**方法二：手动打开**

在 Edge 地址栏输入：`edge://extensions`

然后：

1. 打开左侧 **「开发人员模式」** 开关
2. 点击 **「加载解压缩的扩展」**
3. 选择文件夹：

```
C:\path\to\求职助手\apps\extension\dist
```

4. 加载成功后，工具栏会出现 **「求职助手」** 图标

### 6.2 固定插件到工具栏（可选）

> **找不到图钉？没关系，这一步不是必须的。** 不固定也能用，见下方「不固定时怎么用」。

**方式 A：从扩展菜单固定（部分 Edge 版本有）**

1. 点击 Edge 右上角 **扩展** 图标（拼图 🧩，在地址栏右侧）
2. 在弹出列表里找到 **「求职助手 - BOSS直聘 (Edge)」**
3. 若右侧有 **图钉 📌** 图标，点一下变蓝即表示已固定到工具栏

**方式 B：在扩展管理页设置（更常见）**

1. 打开 `edge://extensions`
2. 找到求职助手插件卡片
3. 查看是否有 **「在工具栏中显示」** / **「Show in toolbar」** 开关，打开即可

**不固定时怎么用**

- 每次点击右上角 **拼图扩展图标** → 在列表里点 **「求职助手」** 即可打开插件主面板

**若列表里根本没有求职助手**

说明插件还没加载成功，请回到 [6.1](#61-加载插件首次) 检查 `apps\extension\dist` 是否选对，或 extension 构建窗口是否报错。

### 6.3 更新插件

修改代码或重新构建后：

1. 打开 `edge://extensions`
2. 找到求职助手插件
3. 点击 **「重新加载」** 按钮

### 6.4 侧边栏要求

- 需要 **Edge 114 及以上**
- 点击工具栏 **求职助手** 图标直接打开主面板（无需弹窗中转）

## 7. 日常使用流程

以下是每次求职时的标准操作流程：

```
上传简历（首次） → 配置筛选（首次/有变化时）
       ↓
启动服务（启动求职助手.bat）
       ↓
BOSS 直聘浏览岗位 → 打开岗位详情页
       ↓
插件侧边栏 → 生成打招呼语 → 编辑（可选）
       ↓
填入 BOSS 输入框 → 手动点击发送
       ↓
管理台查看记录、调整状态
```

### 详细步骤

#### ① 启动服务

双击项目根目录 **`启动求职助手.bat`**（或 `JobAssistant\JobAssistant.exe`）。程序会自动启动服务并打开管理台窗口。

#### ② 在 BOSS 直聘找岗位

1. 用 **Edge** 打开 https://www.zhipin.com 并登录
2. 搜索并点击进入 **岗位详情页**
   - URL 通常包含 `job_detail` 或 `/job/`
   - 必须在详情页，列表页无法完整抓取 JD

#### ③ 打开插件

- 点击工具栏 **求职助手** 图标即可打开主面板

侧边栏会显示：

- API 连接状态
- 当前岗位名称、公司、薪资、城市
- 匹配分（若已同步到 API）

若显示「未检测到岗位信息」，点击 **「刷新」** 按钮。

#### ④ 生成打招呼语

1. 确认 API 显示 **已连接**
2. 点击 **「生成打招呼语」**
3. 等待 3–10 秒，话术出现在下方文本框
4. 可手动修改话术内容

#### ⑤ 填入并发送

1. 在 BOSS 页面打开与该岗位的 **沟通/聊天窗口**（如需填入聊天框）
2. 回到侧边栏，点击 **「填入 BOSS 输入框」**
3. 回到 BOSS 页面，**检查话术内容**
4. **手动点击发送**（系统不会自动发送）

#### ⑥ 在管理台跟进

1. 打开 http://127.0.0.1:8000/jobs
2. 浏览过的岗位会自动出现在列表中
3. 可标记 **已沟通**、**跳过**，或查看话术历史

## 8. Web 管理台说明

管理台左侧为**侧边导航栏**，包含：仪表盘、BOSS直聘岗位、官网招聘源、官网岗位、简历管理、目标岗位、设置、快速上手。

### 8.1 快速上手

路径：http://127.0.0.1:8000/quick-start

首次使用请从此页开始，按步骤完成：启动服务 → 上传简历 → 配置 API → 安装 Edge 插件 → BOSS 投递 → 管理台跟进。

### 8.2 仪表盘

路径：http://127.0.0.1:8000/

| 指标 | 含义 |
|------|------|
| 岗位总数 | 插件同步过的所有岗位 |
| 今日新增 | 今天新抓取的岗位数 |
| 待处理 | 状态为「待处理」的岗位 |
| 已沟通 | 已生成/发送过话术的岗位 |
| 已跳过 | 你标记为跳过的岗位 |
| 平均匹配分 | 所有岗位匹配分的平均值 |

### 8.3 BOSS直聘岗位列表

路径：http://127.0.0.1:8000/jobs

**仅显示** Edge 插件在 BOSS 直聘采集的岗位（与「官网岗位」分开）。

**筛选功能：**

- 按状态筛选：待处理 / 已沟通 / 已跳过
- 按最低匹配分筛选

**操作按钮：**

| 按钮 | 作用 |
|------|------|
| 导出 Excel | 导出 BOSS 岗位 |
| 生成话术 | 调用 AI 生成打招呼语 |
| 打开岗位 | 跳转 BOSS 原链接 |

### 8.4 官网招聘源

路径：http://127.0.0.1:8000/career-sites

用于从**各公司招聘官网**抓取校招/实习岗位（与 BOSS 插件采集相互独立）。

**配置步骤：**

1. 打开「官网招聘源」，点击 **导入精选源并抓取**，或点击单个精选企业名称单独导入
2. 其他公司：在「我的招聘源」中 **手动添加** 校招列表页 URL（如 `xxx.zhiye.com/campus`），保存后抓取
3. 之后可只点 **仅抓取**，或开启定时自动抓取
4. 在「官网岗位」筛选、导出 Excel

**精选源说明：**

- 内置目录仅保留 **实测可抓取** 的北森（zhiye.com）校招页，当前约 **9 家**（讯飞、360、三一、零跑、中金等）
- 目录存于 `apps/api/app/data/career_presets.json`，会随验证结果更新，**不是**全网企业大全
- 字节、腾讯等自建招聘站暂不支持批量导入，需等单独适配或手动尝试添加 URL

**支持的站点类型：**

| 类型 | 说明 |
|------|------|
| 北森 zhiye.com | 当前主要支持，通过 API 抓取校招/实习岗位 |
| Moka（mokahr.com） | 部分公司可用，效果因站点而异 |
| 通用 HTML | 成功率较低，仅作兜底 |
| 纯前端渲染 / 需登录 | 当前版本**无法抓取** |

**定时抓取：**

- 开启后，服务每小时检查一次
- 每个招聘源可单独设置间隔（小时）
- 抓取结果写入本地数据库，可在侧边栏「**官网岗位**」页筛选，并导出 Excel

**说明与限制：**

- 请仅抓取你有权访问的公开招聘信息，并控制频率，避免对目标网站造成压力
- 官网岗位默认**不做 AI 匹配打分**（匹配分为 0），可在岗位详情中手动「重新匹配」
- 若某公司官网结构特殊，可能需要单独开发适配器

### 8.5 官网招聘岗位列表

路径：http://127.0.0.1:8000/career-jobs

展示从各公司官网抓取到的岗位。支持按**公司、城市、状态、关键词**筛选，并提供实习/校招/社招等快捷标签；可排序、导出 Excel，点击「官网投递」跳转原招聘页。

### 8.7 投递工作台

路径：http://127.0.0.1:8000/applications

1. 已在飞书或 Excel 维护进度时，点击“一键导入进度”并选择 `.xlsx`、`.csv`、`.tsv` 或 `.json` 文件；也可以先点击“下载模板”。
2. 系统自动识别公司、岗位、链接、进度、优先级、渠道、联系人、标签、备注和日期等列。优先按岗位链接去重，没有链接时按“公司 + 岗位”合并；空白单元格不会清空已有内容。
3. 导入完成后查看新增、更新、无变化和失败数量；无法识别的进度、优先级或日期会按行提示，不会覆盖原值。
4. 点击“投递资料”，补全姓名、手机、邮箱、教育与经历，并确保默认简历有 PDF/Word 原文件。
5. 用表格维护优先级、阶段、联系人、下次跟进、面试时间、标签和备注；看板支持拖拽改阶段，日历显示跟进/面试安排。
6. 勾选指定岗位，或不勾选并按“最高优先级范围 + 最低匹配分 + 本轮上限”创建队列。
7. 点击“按优先级自动投递”后，扩展按 P0 → P4、同优先级匹配分从高到低打开岗位；登录、短信、扫码、滑块和默认的最终提交仍由你确认。

> 不同招聘系统的自定义控件差异很大。系统无法确认必填项或提交结果时会停下让你接管，不会把“点击过按钮”直接当作投递成功。

## 9. Edge 插件说明

### 9.1 插件界面

**主面板（点击工具栏图标打开）**

| 区域 | 内容 |
|------|------|
| 顶部 | 标题、使用前检查清单、API / BOSS 连接状态 |
| 当前岗位 | 岗位名、公司、薪资、匹配分 |
| 操作区 | 生成话术、编辑框、填入按钮 |
| 自动投递 | 切换岗位、生成、沟通、填入（可选自动发送） |
| 底部 | 管理台链接（http://127.0.0.1:8000） |

### 9.2 插件能自动做什么

- ✅ 识别 BOSS 岗位详情页
- ✅ 抓取岗位名称、公司、薪资、城市、JD 全文
- ✅ 将岗位同步到本地数据库
- ✅ 调用 AI 生成打招呼语
- ✅ 将话术填入页面输入框
- ✅ **自动投递模式**：在职位列表页自动切换下一个岗位 → 打开「立即沟通」→ 填入话术
- ✅ **优先级网申队列**：打开招聘官网 → 等待登录 → 识别并填写表单 → 提交前确认

### 9.3 手动投递与全自动投递（侧边栏）

侧边栏分为 **手动投递** 与 **全自动投递** 两个区域，可同时使用、互不影响。

**手动模式（自己浏览岗位）**

1. 在 BOSS 打开任意岗位详情页
2. 点击 **「手动刷新」** 抓取并同步到本地 API（显示「刷新中…」，约 12 秒内返回）
3. 可勾选 **「浏览时自动同步岗位」**：切换岗位时自动同步打分，无需每次点刷新
4. 点击 **「生成打招呼语」** → 在 BOSS 打开沟通 → **「填入 BOSS 输入框」**

**全自动模式（批量处理列表）**

1. 在 BOSS 打开 **职位搜索/推荐页**（左侧岗位列表 + 右侧详情）
2. 设置职责/待遇匹配分范围、间隔秒数、本轮上限
3. 点击 **「开始全自动投递」**；运行中可点 **「停止全自动」**，手动功能仍可查看当前岗位

| 选项 | 说明 |
|------|------|
| 职责/待遇匹配分范围 | 两项均落在范围内才会自动投递 |
| 浏览时自动同步 | 仅手动模式：浏览换岗时自动同步，不自动发话术 |
| 间隔（秒） | 全自动模式下每个岗位之间的等待，建议 ≥ 8 秒 |
| 本轮上限 | 本次最多处理多少个岗位 |
| 自动点击「发送」 | **默认关闭**。开启后会自动点发送，有封号风险 |

点击 **「停止」** 可随时中断。

> BOSS 页面结构可能改版，若自动切换岗位失效，请更新插件或查看 `docs/boss-selectors.md`。

### 9.4 默认安全策略

- 默认 **不** 自动点击「发送」，需你手动确认（可在自动投递中勾选开启）
- 不会代替你登录 BOSS
- 不保存任何招聘网站密码；验证码、短信、扫码和滑块由你完成
- 只有处理网申时，才会按你的指令把所选简历上传到当前招聘网站

### 9.5 填入话术的页面要求

「填入 BOSS 输入框」功能需要在 **沟通/chat 页面** 或 **岗位页的沟通弹窗** 中使用，且页面上存在可输入的文本框。

若提示「未找到沟通输入框」：

1. 在 BOSS 页面点击「立即沟通」打开聊天窗口
2. 确认输入框已出现
3. 回到侧边栏再次点击「填入」

## 10. 匹配分说明

系统为每个岗位计算 **三个分数**（范围 0–100）：

| 分数 | 含义 |
|------|------|
| **综合分** | 职责匹配分与待遇匹配分的平均值，用于列表排序与自动投递阈值 |
| **职责匹配分** | 岗位名称、关键词、技能、JD 重叠、岗位性质、排除词等 |
| **待遇匹配分** | 城市、月薪/日薪、双休、五险一金、年终奖、提成、餐补、包住宿等 |

### 职责匹配分主要维度

| 维度 | 说明 |
|------|------|
| 岗位名称与关键词 | 与各层「目标岗位」名称、匹配关键词在 JD 中的命中 |
| 技能关键词 | 简历技能、必须包含词在 JD 中的命中 |
| 岗位性质 | 全职 / 实习 / 兼职 / 校招是否与 JD 一致 |
| 文本相似 | 简历与 JD 的词汇重叠 |
| 排除词 | 含「外包」「驻场」等词会降分 |

### 待遇匹配分主要维度

| 维度 | 说明 |
|------|------|
| 城市 | 是否在目标城市列表中 |
| 月薪 / 日薪 | 岗位薪资是否在对应期望范围内（可同时配置两种） |
| 双休 | 若要求双休，JD 未体现则降分 |
| 五险一金 | 若要求，JD 未提及则降分 |
| 福利期望 | 年终奖、提成、餐补、包住宿等在 JD 中的体现 |

### 如何使用匹配分

- **综合 70 分以上**：建议重点关注，生成话术投递
- **50–70 分**：可看 JD 详情再决定；可对比职责分与待遇分哪一侧偏低
- **50 分以下**：可考虑直接「跳过」

在岗位列表筛选「最低匹配分 70」可快速过滤低匹配岗位（按综合分）。插件自动投递需 **职责分与待遇分同时落在各自设定范围内** 才会投递；配置会保存在浏览器本地，下次打开插件面板仍生效。

## 11. 话术生成规则

### AI 生成（已配置 API Key）

- 长度：约 80–150 字
- 风格：按设置中的「简洁 / 正式 / 热情」
- 内容要求：
  - 提及 1–2 个 JD 关键词
  - 结合 1 个真实项目或经历亮点
  - 禁止空话和编造内容

### 本地模板（未配置 API Key）

系统会使用简单模板，例如：

> 您好，看到贵司「XXX」岗位，我有 Python、React 等经验，有相关岗位实践经验，与 JD 要求较匹配，方便进一步沟通吗？

模板话术较通用，**强烈建议配置 AI Key** 以获得更好效果。

### 发送前检查清单

- [ ] 岗位名称和公司是否正确
- [ ] 话术中提到的技能、项目是否真实
- [ ] 长度是否合适（不宜过长）
- [ ] 有无错别字
- [ ] 语气是否符合你的风格

- 建议不要将 `.env` 和 `data/` 目录提交到公开代码仓库

```

.env
```

可使用 MySQL 工具导出 `job_assistant` 数据库。

## 13. 常见问题

### Q1：插件显示「API 未连接」

**原因**：后端服务未启动或端口被占用。

**解决**：

1. 双击 `启动求职助手.bat`，等待管理台窗口弹出
2. 浏览器访问 http://127.0.0.1:8000/health ，应返回 `{"status":"ok"}`
3. 在插件侧边栏等待几秒或点击刷新

### Q2：抓取不到岗位信息

**原因**：不在岗位详情页，或 BOSS 页面结构已更新。

**解决**：

1. 确认 URL 包含 `job_detail` 或类似岗位详情路径
2. 点击侧边栏「刷新」
3. 刷新 BOSS 页面后重试
4. 若仍失败，可能是页面改版，需等待软件更新

### Q3：AI 生成失败或很慢

**原因**：API Key 无效、网络问题或 AI 服务繁忙。

**解决**：

1. 在设置页检查「分析 API」是否已添加 Key 并选中为当前使用
2. 检查网络能否访问 AI 服务
3. 未配置 Key 时会自动使用本地模板，可正常使用但质量较低

### Q4：填入输入框失败

**原因**：未打开聊天窗口，或页面无输入框。

**解决**：

1. 在 BOSS 点击「立即沟通」打开聊天
2. 确认输入框可见
3. 再次点击「填入 BOSS 输入框」

### Q5：匹配分感觉不准

**原因**：简历解析不完整或筛选条件过宽/过窄。

**解决**：

1. 在设置中完善目标岗位、关键词
2. 重新上传格式清晰的简历
3. 在岗位详情点击「重新匹配」

### Q6：Edge 侧边栏打不开

**原因**：Edge 版本过低。

**解决**：

1. 升级 Edge 到 114 及以上（设置 → 关于 Microsoft Edge）
2. 确认已重新加载插件（`edge://extensions` → 重新加载）
3. 不要在 `edge://extensions` 页面点击图标测试，请切换到普通网页后再点

### Q7：双击 exe 报 `_ctypes` / DLL 找不到

**原因**：使用了项目根目录**单独一个** `JobAssistant.exe`，或只复制了 exe 没有带上 `JobAssistant` 文件夹里的 `_internal` 等依赖文件。

**解决**：

1. 删除根目录下孤立的 `JobAssistant.exe`（若有）
2. 重新运行 `.\scripts\build-launcher.ps1` 生成完整的 `JobAssistant` 文件夹
3. 使用 **`启动求职助手.bat`** 或 **`JobAssistant\JobAssistant.exe`** 启动

### Q8：启动脚本报错「请先运行 install.ps1」

**解决**：

```powershell
.\scripts\install.ps1
```

### Q9：修改代码后插件没变化

**解决**：

1. 确认 extension 构建窗口无报错
2. 打开 `edge://extensions`，点击插件的 **「重新加载」**

### Q10：管理台页面打不开

**解决**：

1. 确认启动器已「一键启动」，API 在 8000 端口运行
2. 访问 http://127.0.0.1:8000（不要用 https）
3. 检查防火墙是否拦截本地端口

### Q11：简历上传失败

**解决**：

1. 确认文件为 `.pdf` 或 `.docx`
2. 旧版 `.doc` 格式请另存为 `.docx`
3. 确认文件未加密、可正常打开
4. 扫描版 PDF 可能无法提取文字，建议使用可选中文本的 PDF

### Q12：MySQL 连接失败

**原因**：MySQL 未启动、密码错误或端口不对。

**解决**：

1. 确认 MySQL 服务已启动（Windows 服务或 XAMPP 等）
2. 检查 `.env` 中 `MYSQL_PASSWORD`（常见为 `123456` 或 `1234`）
3. 命令行测试：`mysql -u root -p` 能否登录
4. 修改 `.env` 后需 **重启 API 窗口**

## 14. 使用建议与注意事项

### 建议使用方式

1. **每天投递前**双击 `启动求职助手.bat` 启动，用完后**关闭启动器窗口**即可停止服务
2. **先配置再投递**：完善设置里的目标岗位和排除词，减少无效沟通
3. **人工审核话术**：AI 生成后务必读一遍再发送
4. **控制频率**：建议每日沟通不超过 30 个，避免平台限制
5. **高匹配优先**：优先处理 70 分以上的岗位

### 注意事项

| 事项 | 说明 |
|------|------|
| 平台规则 | 请遵守 BOSS 直聘用户协议，本工具仅供个人求职使用 |
| 不自动发送 | 避免误投和账号风险 |
| API 费用 | 使用 DeepSeek 等 AI 服务可能产生少量 API 费用 |
| 页面改版 | BOSS 页面更新可能导致抓取失效，需等待适配更新 |
| 开发者模式 | Edge 插件以「解压缩扩展」方式加载，重启浏览器后仍保留，但需保持 `dist` 目录存在 |

### 推荐工作流（高效版）

```
早上：启动服务 → 上传/检查简历 → 调整设置
      ↓
上午：BOSS 搜岗 → 只看 70+ 匹配分 → 批量生成话术
      ↓
下午：逐个审核 → 填入 → 手动发送 → 管理台标记状态
      ↓
晚上：管理台回顾今日投递 → 规划明日关键词
```

### 关键路径

| 路径 | 说明 |
|------|------|
| `apps\extension\dist` | Edge 插件加载目录 |
| MySQL `job_assistant` | 岗位和话术数据库 |
| `data\resumes\` | 上传的简历文件 |
| `.env` | AI Key、MySQL 密码等配置 |

### 岗位状态说明

| 状态 | 含义 |
|------|------|
| 待处理 | 已同步，尚未沟通 |
| 已沟通 | 已生成/发送过话术 |
| 已跳过 | 主动标记为不感兴趣 |
| 已投递 | 预留状态，可手动标记 |
